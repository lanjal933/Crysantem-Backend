Preguntas Frecuentes

¿Qué es MyIA?
MyIA es la plataforma de Crysantem que te permite crear y configurar un asistente de inteligencia artificial para tu página web sin necesidad de programar.
¿Necesito saber programar?
No. MyIA está diseñado para configurar tu asistente mediante una interfaz visual sin necesidad de escribir código.
¿Cómo se configura el asistente?
El proceso incluye seleccionar un plan, configurar la apariencia, definir el comportamiento, preparar la información y conectar las integraciones según el plan elegido.
¿Qué información utiliza para responder?
El asistente utiliza la información que cargás sobre tu negocio, incluyendo servicios, productos, FAQs y, según el plan, datos de Google Sheets o Calendar.
¿Qué opciones incluye cada plan?
El plan Responde incluye atención básica. Asiste agrega Google Sheets y Markdown enriquecido. Automatiza incluye Google Calendar y gestión de citas. Enterprise ofrece integraciones personalizadas.
¿Cómo puedo empezar?
Comenzá seleccionando un plan en nuestra página de planes y siguiendo el proceso de configuración en MyIA. También podés contactarnos para evaluar soluciones personalizadas.
